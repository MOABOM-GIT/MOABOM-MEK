## 이동 내역 (2026-05-30)

- `ai-tools/README.md` → `unused/ai-tools/README.md`
- `ai-tools/devtools/README.md` → `unused/ai-tools/devtools/README.md`
- `ai-tools/agents/README.md` → `unused/ai-tools/agents/README.md`
- `ai-tools/skills/*.md` → `unused/ai-tools/skills/*.md`

## 원칙

- 실행/운영 체인에서 참조되는 핵심 가이드는 `app/docs/` 루트에 유지
- 참고/배경/도구성 문서는 `app/docs/unused/`로 이동
- 이동 시 `app/docs/README.md` 링크를 반드시 함께 갱신
